วงนี้มีเกม (Party Game Hub)
"วงนี้มีเกม" คือเว็บแอปพลิเคชันสำหรับเล่นเกมปาร์ตี้ที่ครบเครื่องที่สุด ออกแบบมาเพื่อสร้างสีสันในงานสังสรรค์กับกลุ่มเพื่อน ไม่ว่าจะเป็นทริปแคมป์ปิ้ง งานวันเกิด หรือแค่รวมตัวนั่งชิลล์กันก็สนุกได้ทันที!

✨ ฟีเจอร์หลัก (Key Features)
15+ เกมปาร์ตี้สุดฮิต: ตั้งแต่ Truth or Dare, ทายคำบนหัว, จระเข้งับนิ้ว ไปจนถึง ศึกจิ้มไว

ระบบเซ็นเซอร์เอียงจอ (Gyroscope): สำหรับเกมทายคำบนหัว (หงายจอ = ถูก, คว่ำจอ = ข้าม)

ระบบเสียงประกอบ (Sound Effects): เพิ่มความตื่นเต้นด้วยเสียงเอฟเฟกต์ในเกม

บันทึกสถิติ (Hall of Fame): สรุปผลปาร์ตี้ พร้อมบันทึกว่าใครโดนทำโทษบ่อยที่สุด

ใช้งานออฟไลน์ (PWA): สามารถ Add to Home Screen และเล่นได้แม้ไม่มีอินเทอร์เน็ต

กันจอดับ (Wake Lock API): หน้าจอจะไม่ดับขณะกำลังเล่นเกม

ปรับแต่งได้เอง: สร้างคำถามหรือคำใบ้ในแบบฉบับของกลุ่มเพื่อนตัวเองได้

🛠️ รายการเกมภายในแอป
ทายคำบนหัว: เกมใบ้คำพร้อมระบบเซ็นเซอร์เอียงจอ

จระเข้งับนิ้ว: รูเล็ตต์วัดดวงสุดตื่นเต้น

สปายจับผิด: ล่าหา Spy ในกลุ่มเพื่อน

ใบ้คำห้ามพูด: ท้าทายความสามารถในการอธิบายโดยห้ามพูดคำต้องห้าม

ศึกจิ้มไว: เกมรัวนิ้วแข่งกันบนหน้าจอ

และเกมอื่นๆ: เช่น Hot Potato, Most Likely To, 5 Sec Challenge และอีกมากมาย

🚀 วิธีการใช้งาน
เข้าใช้งาน: เปิดผ่านบราวเซอร์ที่ [ใส่ URL เว็บไซต์ของคุณที่นี่]

เพิ่มผู้เล่น: พิมพ์ชื่อเพื่อนแต่ละคนลงในช่องเพิ่มผู้เล่น ระบบจะสุ่มอิโมจิประจำตัวให้โดยอัตโนมัติ

เลือกเกม: เลือกเกมที่ต้องการจากหน้าหลัก

สนุกกับปาร์ตี้: ทำตามวิธีเล่นที่ปรากฏใน "กล่องคู่มือวิธีเล่น (Game Rules Box)" ของแต่ละเกม

สรุปผล: กดปุ่ม "จบปาร์ตี้" เพื่อดูสถิติผู้รอดชีวิตและสรุปผลความสนุก

📱 การติดตั้งลงมือถือ (PWA)
เพื่อให้ประสบการณ์การเล่นที่ดีที่สุดและใช้งานแบบออฟไลน์ได้:

iOS (Safari): กดปุ่ม Share (แชร์) -> เลือก "Add to Home Screen" (เพิ่มไปยังหน้าจอโฮม)

Android (Chrome): กดปุ่ม 3 จุด -> เลือก "Add to Home Screen" (เพิ่มไปยังหน้าจอโฮม)

🛠️ เทคโนโลยีที่ใช้
Frontend: HTML5, CSS3, JavaScript (Vanilla)

API: Screen Wake Lock API, Web Audio API, Service Worker, Web Manifest

Storage: LocalStorage (สำหรับการเก็บข้อมูลเกมและคำถาม Custom)

ขอให้สนุกกับปาร์ตี้และ "วงนี้มีเกม" นะครับ! 🥳
